# Cairo document fonts

Regular and Bold are the unmodified static Cairo 2.010 release from Google Fonts, commit `e86936fd5b72936fe1eed526b69d49343a7d353b`:
https://github.com/google/fonts/tree/e86936fd5b72936fe1eed526b69d49343a7d353b/ofl/cairo

These static files support mPDF 8 Arabic OpenType shaping without the unsupported MarkGlyphSets lookup flags in the previous bundled font files. The same files are served to browser print views. Licensed under the SIL Open Font License; see OFL.txt.
